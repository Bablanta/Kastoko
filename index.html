💡 Solusi Cetak Nota & Info WebSerial

✅ Solusi Cepat: Printer USB Anda Sudah Siap Digunakan!
Jika printer thermal USB Anda sudah dicolok ke komputer Windows (driver POS-58 / POS-80 / Epson / Xprinter / Panda), Anda TIDAK PERLU menghubungkan WebSerial.
Cukup klik tombol "🖨️ Cetak via Driver Windows" di bawah untuk langsung mencetak nota.
Mengapa pesan "Browser tidak mendukung WebSerial" muncul?
  • Peramban Non-Chromium: Firefox, Safari, dan browser ponsel secara standar tidak mendukung akses port USB langsung (WebSerial).
  • Akses via IP Jaringan (LAN): Jika membuka lewat IP (misal: http://192.168.1.xxx:8080), Google Chrome / Edge otomatis mengunci WebSerial demi keamanan browser.
Jika Anda tetap ingin menggunakan fitur Direct ESC/POS (tanpa Driver Windows):
  1. Gunakan peramban Google Chrome atau Microsoft Edge.
  2. Buka aplikasi lewat alamat lokal: http://localhost:8080.
